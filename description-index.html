AI-Powered Development with Gemini

This dashboard was built through an iterative process in collaboration with Gemini. The AI assisted in bridging the gap between raw GIS data and a functional web interface by providing:

  • Code Architecture: Structuring the ArcGIS Maps SDK for JavaScript and optimizing the UI for a professional dashboard feel.
  • Logic Synthesis: Developing Arcade expressions for real-time building IDs and dynamic height extrusions based on geographic center points.
  • Problem Solving: Debugging complex rendering issues and ensuring persistence across different basemap changes.

3D Building Heights

Building heights are generated dynamically using an Arcade Expression. The logic uses the surface area of each polygon to estimate a realistic height. Smaller buildings are assigned residential-scale heights, while larger footprints are extruded further to simulate commercial or industrial complexes. A coordinate-based seed adds randomness to create a realistic urban skyline.

Analysis Tools

The dashboard features several critical urban analysis layers:

  • Emergency Routing (Fire & Police): Visualizes optimized response paths from local stations to areas like Öxnehaga, including travel-time calculations.
  • Hospital Access: Shows the most efficient route to Ryhov County Hospital for healthcare accessibility insights.
  • Service Areas (Walking Analysis): Uses a 0-15 minute buffer analysis to identify "walkability deserts" categorized by time intervals.

Dynamic Map Layers

All Point of Interest (POI) data is pulled from custom GeoJSON datasets. Each category uses custom SVG icons, with visibility toggled dynamically via the sidebar interface.

Lessons for Future Projects

Throughout the project, we discovered that Gemini was not always optimal for specific coding tasks and technical troubleshooting. We also tested alternative tools like Lovable and Codex, which showed great potential. However, usage of these tools was limited because they only offer a certain number of free tokens per day, meaning we could not utilize their full capacity for this project.
